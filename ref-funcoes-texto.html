SQL Funções de Texto

Esta é a página de consulta rápida das funções que trabalham com texto no SQLite 3.50: juntar, medir, cortar, trocar, limpar e formatar. Cada linha das tabelas traz um exemplo e o resultado que ele dá de verdade. A explicação passo a passo, com exercícios, está na aula Funções de Texto.

Como ler as tabelas
  • Exemplo é o que vai dentro de um SELECT: para testar, escreva SELECT antes e ; depois, como em SELECT upper('Ana');.
  • Resultado foi colhido no editor do guia (SQLite 3.50.4). NULL quer dizer "sem valor". Espaços que importam aparecem entre colchetes, como [Ana   ].
  • Texto vai sempre entre aspas simples. Para pôr uma aspa dentro do texto, dobre-a: 'Loja D''Água'.
  • Quase todas as funções devolvem NULL quando recebem NULL (as exceções estão marcadas).

Com dados da Loja Aurora: o || monta "cidade (UF)", e o concat_ws lida bem com o estado NULL dos fornecedores estrangeiros:

SELECT nome,
       concat_ws(' / ', cidade, estado, pais) AS local
FROM fornecedores;

Repare nas linhas de Porto e Buenos Aires: o estado é NULL, e o concat_ws simplesmente o pulou. Com cidade || ' / ' || estado || ' / ' || pais, essas duas linhas sairiam NULL inteiras.

Acentos e maiúsculas no SQLite

O SQLite que vem pronto só sabe trocar a caixa das 26 letras do alfabeto inglês (A a Z). Letras como é, ç, ã ficam como estão. Veja nos clientes da loja:

SELECT nome, upper(nome) AS maiusculo, length(nome) AS letras
FROM clientes
WHERE id IN (1, 5, 9);

O length conta certo (as letras acentuadas valem 1), mas o upper deixou é, ç, ã e ô minúsculos. Para trocar a caixa de qualquer letra, o SQLite precisa de uma extensão chamada ICU, que não vem no editor do guia nem no sqlite3 padrão. Os outros bancos (MySQL, PostgreSQL, SQL Server) tratam os acentos corretamente.

Combinando substr e instr: tudo o que vem depois do @ do email (o domínio):

SELECT nome, substr(email, instr(email, '@') + 1) AS dominio
FROM clientes
WHERE id <= 3;

O uso mais comum na loja: mostrar o preço com duas casas.

SELECT nome, format('R$ %.2f', preco) AS preco
FROM produtos
WHERE id <= 3;
Vírgula ou ponto?

O format sempre usa ponto nos decimais e vírgula no milhar, como nos Estados Unidos. Para o formato brasileiro (R$ 1.234,50), troque os sinais com replace ou, melhor, deixe a formatação para o programa que mostra os dados ao usuário.

Experimente

Missão: o catálogo da loja precisa mostrar o preço como texto, com R$ e duas casas (R$ 1.15, R$ 12.35…). Mostre o nome de todos os produtos e o preço formatado numa coluna chamada preco_txt.

SELECT nome, preco
FROM produtos;

SELECT nome, format('R$ %.2f', preco) AS preco_txt
FROM produtos;

Livre: teste qualquer função desta página. Troque os nomes, junte funções umas dentro das outras.

SELECT nome,
       upper(substr(nome, 1, 1)) AS inicial,
       length(nome) AS letras,
       replace(nome, ' ', '_') AS sem_espacos
FROM clientes
LIMIT 5;

Resumo

  • Juntar: || (com NULL vira NULL), concat e concat_ws (pulam os NULL).
  • Medir: length em letras, octet_length em bytes.
  • Cortar e procurar: substr(x, início, n) (início 1, negativo conta do fim), instr, replace.
  • Limpar: trim, ltrim, rtrim, com ou sem a lista de letras.
  • Formatar: format / printf com %s, %d, %.2f, %05d.
  • upper, lower, LIKE e NOCASE só tratam as letras sem acento.
  • Não existem no SQLite: LEFT, RIGHT, LPAD, REPEAT, LEN; use substr e printf.
