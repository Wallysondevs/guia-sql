SQL Comandos de Ponto do sqlite3

Os comandos de ponto são os comandos que começam com . no programa sqlite3, o terminal do SQLite: .tables, .schema, .mode… Eles não são SQL: são ordens para o próprio programa, para mostrar o banco, mudar o jeito de exibir os resultados, ler e gravar arquivos. Esta página lista todos os do sqlite3 3.50.4, com a descrição original do .help traduzida e as saídas reais do terminal da Ana. A aula que ensina os principais é Comandos de Ponto.

As regras dos comandos de ponto
  • Começam com . no começo da linha, e vão um por linha.
  • Não levam ; no fim (o ; é do SQL).
  • Só existem no programa sqlite3. No editor do guia, no PHP, no Python e em qualquer outro programa, eles não funcionam: o editor responde near ".": syntax error.
  • Digitou um que não existe? O sqlite3 responde Error: unknown command or invalid arguments: "tabels". Enter ".help" for help (veja Erros Comuns).
  • Quase todos podem ser abreviados, desde que não fiquem ambíguos: .tab funciona como .tables. Nesta página, use sempre o nome completo.

E no editor do guia?

Nenhum comando de ponto funciona no editor, porque ele roda só SQL. Para quase todos os de "ver o banco", existe um jeito em SQL, que funciona em qualquer programa:

No terminalEm SQL (funciona no editor)
.tablesSELECT name FROM sqlite_schema WHERE type = 'table';
.schema categoriasSELECT sql FROM sqlite_schema WHERE name = 'categorias';
.indexesSELECT name FROM sqlite_schema WHERE type = 'index';
as colunas de uma tabelaSELECT name, type FROM pragma_table_info('clientes'); (veja PRAGMAs)
.versionSELECT sqlite_version();

Resumo

  • Comandos de ponto são do programa sqlite3, não do SQL: começam com ., um por linha, sem ;.
  • Ver o banco: .tables, .schema, .indexes, .databases, .show.
  • Exibição: .mode box (ou table, column, csv, json…), .headers on, .nullvalue, .width, .timer on.
  • Arquivos: .once/.output para gravar, .import para ler CSV, .read para rodar um .sql, .dump e .backup para cópias.
